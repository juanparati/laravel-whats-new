Headline features

The additions with the biggest day-to-day impact — each is a new capability, not a tweak to an existing one.

First-party image processing

A built-in Image facade/driver (GD or Imagick) for resizing, cropping, format conversion, dominant-colour detection, HEIC/AVIF, streaming and Responsable output — no third-party library required.

#59276#61110#61111#61109#60932#60922

Cloud facade & managed queues

A new Cloud facade and a first-class managed-queue driver for Laravel Cloud, with queue metrics, config caching, and Queue::forward() / managedQueues() helpers. Since 13.30 it also wires up Cloud read replicas, native Postgres pooling and IAM-backed S3 disks.

#61275#60180#60122#61188#61665#61668#61676

Read-through filesystem disks

A disk type that transparently falls back to — and copies from — a second disk on a cache miss, with an option to skip copying and support for moving fallback-only files.

#61140#61155#61272

Declarative PHP attributes

A broad new attribute system — #[Queue], #[Delay], #[Middleware], #[Authorize], #[BindWhen], #[Signature] — for configuring jobs, controllers, form requests and commands without boilerplate.

#58578#59030#59048#60862

artisan dev

A single command that runs Vite, the queue worker, log tailing and more concurrently via @laravel/multiplex, plus dev:list to inspect what's registered. Since 13.30 you can order commands and opt out of the vendor defaults.

#60412#60573#61100#61344#61575

Form request strict mode

Form requests can now reject any input field they don't explicitly expect, closing a common mass-assignment surface. As of 13.35, _token and _method are ignored.

#59430#61891

Mercure broadcasting 13.32

A first-party Mercure broadcast driver, installable through install:broadcasting (now with --pretend), with support for relative hub URLs.

#61474#61587#61629#61633

Cross-disk copy & move 13.32

copyToDisk() / moveToDisk() on any filesystem adapter, taking a disk name, enum or filesystem instance as the target.

#61511#61519#61867
